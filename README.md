# Montante

Simulador educacional de investimentos do projeto acadêmico A3. As projeções são hipotéticas e o aplicativo funciona localmente, sem transações reais.

## Executar

Na raiz, com Node.js 22+ e Python 3 instalados:

```sh
npm start
```

Abra [http://127.0.0.1:4178](http://127.0.0.1:4178). Os módulos JavaScript usam HTTP. A aplicação estática dispensa dependências e etapa de build.

```sh
npm run lint
npm test
```
