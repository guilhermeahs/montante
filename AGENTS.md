# Montante

Leia README.md e CONTINUIDADE.md antes de editar. Confira a árvore de trabalho e o remoto.

- Use HTML semântico, CSS responsivo e módulos ES em JavaScript. Mantenha a interface em português brasileiro.
- Separe lógica financeira, estado persistido, renderização e provedores de dados.
- Aportes entram no fim de cada mês. Use taxas efetivas, comparação com a mesma base e valores de carteira em centavos.
- Use `npm start`, `npm run lint` e `npm test`. Valide rotas e ações no navegador antes de concluir.
- Atualize CONTINUIDADE.md em cada marco. Faça commits pequenos e push normal quando autorizado. Preserve os PDFs, a licença e o histórico.
